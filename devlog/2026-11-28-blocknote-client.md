# 在 Redraft 中打开就写，退出后按正文找回

作者选定 BlockNote 后，Redraft 保留原生窗口、文章库、批注取舍与段落历史。标题可稍后填写，正文首行会成为无标题稿在库中的名称。按 `⌃⌘S` 打开文章库，标题、正文和表格里的文字都能用来找稿。[选型记录](2026-11-28-writing-client-options.md)

## 写作与批注

整个稿件使用一个加载本地资源的 `WKWebView`。BlockNote 0.57 负责输入、选区、`/` 菜单、排版和撤销。`ArticleSession` 核对稿件及基准版本后接收结构化内容。嵌套块、图片和表格都保留可供批注引用的身份。阅读建议时锁定原文，只有作者确认成稿才更新正文。旧的原生编辑控件、排版菜单、图片导入和键盘导航实现已移除。历史视图仍使用原生只读渲染。

本轮把普通包和第三方许可一并打进应用。图片只从本地导入，字节在上传时过桥，打字、撤销和导出使用本地资源标识。换图后撤销可读回旧图，Markdown 附件取自被导出的稿件版本。再次导出到同一目录会得到独立的文件夹。

## 本地文章库与 Agent

SQLite 按文章事务保存正文、版本、待处理取舍、完成轮次和改写范例。启动空稿保持在内存，作者输入正文或标题后开始收录。输入期间约每 400 毫秒合并保存一次，窗口关闭、失焦和正常退出时也会写盘。失败时保留内存稿并提示作者；损坏或版本未知的库会显示打开错误。检索目前在载入内存的稿件中完成。

「复制摘录给 Agent」将当前块内的选区或当前块、文章 ID、修订号、块 ID 和作者要求写入剪贴板。应用内的「试读示例批注」走现有 `ReviewProviding` 流程。外部会话初始化、查证资料回写与自动分类留待后续开发。

## 验证记录

| 场景 | 结果 |
| --- | --- |
| 文档与审阅 | 28 项 Core 测试通过，包括旧稿兼容、嵌套格式、表格身份、换图撤销重做、中文字与 emoji 的选区，以及修改 Unicode 表示后的偏移更新。 |
| 窗口与编辑 | 15 个窗口状态场景和真实 WKWebView 编辑测试通过，覆盖首焦点、分段、撤销重做、批注锁定、组字时另一窗口更新正文、Markdown 与附件的重复导出。 |
| 正文资源 | 7 个本地文件浏览器测试通过，覆盖中文块菜单、选区工具栏、跨块删除与撤销、图表下方续写、组合输入和本地图片。 |
| 稿库 | 5 组独立 SQLite 连接测试通过，覆盖自动保存、重开、字面量 `$null`、批注取舍、跨文章范例顺序、事务回滚、重试和过期写入。 |
| App 冷启动 | 两次独立的应用进程使用同一个临时 SQLite 文件。第一次在正文写下无标题稿，插入本地 PNG 和表格，给首段加批注。第二次从原生菜单打开文章库，在搜索框输入只出现于表格内的「窗边记录七号」，找回同一文章、修订号和批注，WebKit 重新显示正文、表格及图片。两次启动后数据库中仅有 1 篇稿件，完整性检查通过。 |
| 界面 | 已生成 7 张原生窗口快照，检查了浅色图文表、深色正文和 780 点宽的批注阅读窗口。 |

系统拼音候选窗的手动确认与取消仍待实机体验。BlockNote 的表格快照没有行列 UUID，发生歧义时会让已有单元格引用失效，避免将批注挂到另一格。当前支持规则矩形表格。

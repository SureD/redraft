# 原生 UI 与交互

依据 [本轮设计](../technical.md#原生-ui数据模型与状态归属2026-11-15)，在 `design` 分支保留网页原型，并带入 `main` 的 SwiftUI / AppKit、XcodeGen 和 RedraftCore 骨架。核心包的六个文件与 `main` 保持一致，本轮没有实现 Loro、AI、持久化或核心 Diff。

原生界面覆盖文章库、搜索与新建、排版工具栏、图文表正文、段落标记、逐处审阅、版本对照、来历检查器和改写范例。根入口唯一持有 `WorkspaceViewModel`，`WorkspaceState` 管理文章与交互状态；视图通过绑定和动作回写。固定示例提供可体验的改稿流程，阳台示例将换图、图注、单元格、增行、删列与正文拆成独立取舍。审阅完成只记录本次预览的决定，不冒充真实定稿合成。

正文用 TextKit 2。排版保留混合选区中各段、各字已有的属性，并支持原生格式撤销。表格采用稳定行列 ID，防止删插后的旧输入回调写错单元格；异步流程按文章隔离。文章切换重置阅读位置，检查器和范例可定位来源块。审阅对照按可用宽度分为双列或上下排，窄窗口将侧栏和检查器收起为抽屉。

图片文件选择、粘贴和拖入共用 20 MB 及格式校验；异步导入固定原文章和插入锚点，普通富文本粘贴仍交给原生编辑器。表格支持 Tab / Shift-Tab、文字边界处的上下左右导航；选中整块后的 Delete / Esc / Enter 与输入焦点隔离，避免在写字时误删图表。

侧栏、工具栏和检查器使用 `NSVisualEffectView`，跟随窗口激活与系统外观；正文保留不透明暖白 / 炭灰纸面。降低透明度或提高对比度时回退到不透明系统背景。菜单、sheet、选区和键盘交互沿用原生组件，检查器默认收起。

验证采用项目构建、核心包测试、UI 状态回归、原生编辑器交互测试及严格 Swift 格式检查。`make snapshots` 在独立原生测试窗口渲染写作、表格、日记、审阅、历史、范例和空白文章，覆盖 1220 × 820、780 × 820、深浅色共十张截图，同时检查真实 TextKit 2 和原生材质视图。截图输出在忽略目录 `.build/ui-snapshots`，不读取用户桌面。

核心包 3 个测试、UI 状态 8 组场景、编辑器 9 组场景通过，覆盖取消与跨文章隔离、选区边界、模态提交、独立图文表取舍、混合排版、原生撤销与组字保护、表格稳定身份、剪贴板分类和异步图片导入。

最终 macOS Debug 构建、严格格式检查和原生渲染检查通过。已目视核对上述页面及窄窗双列对照，修复了标题初始全选、日期语言、排版工具栏颜色、空白正文入口和窄窗工具栏裁切；架构页已按源码更新核对基线。

本轮内容仅保留在运行内。跨块连续选择、统一文档级撤销、真实逐句溯源和版本合成留待文章会话接入；系统拼音的端到端操作、VoiceOver 朗读及 macOS 13 实机尚未覆盖。最低 macOS 13 的编译兼容性由构建目标和独立测试编译检查。

# 交互原型：减法与富文本排版

- **缘由**　用户反馈界面“AI 味”重：按钮和状态处处带解释，像在教人用。希望像 iOS 备忘录一样安静，同时能像 Google 文档那样在上方直接调整排版。这推翻了上一轮“正文是纯文本，不放格式按钮”的取舍。
- **改动（减法）**　去掉窗口工具栏的标题和保存状态行、写作页横幅、元信息里的字数段数、默认打开的检查器、检查器的引导段落和提示、标记段落的卡片底色与标签（改为正文左侧一道细竖线，悬停看要求，点击换要求）、`Aa` 显示设置、工具栏上的状态数字、工具提示里的原因说明、审阅卡片边框和按钮里的快捷键提示、范例页导语、侧栏的原型说明，以及打字和排版的撤销提示条。主按钮只在需要时出现：有标记时是“改稿 N”，改稿中是进度和取消，待审阅时是“审阅”，审阅中是“完成”。次要操作放进“更多”。
- **改动（排版）**　顶部排版工具栏从左到右：撤销、重做｜正文和标题 1–3、引用｜字体（黑体、宋体、楷体、等宽）｜字号减、字号、字号加｜粗体、斜体、下划线、删除线｜文字颜色、高亮｜对齐｜行距｜项目符号、编号列表｜减少、增加缩进｜清除格式；右端固定“标记给 AI 改稿”和“更多”。按钮反映选区的当前状态，混合时显示为半按下或留空；按下不夺走正文焦点，选区原样保留；常见快捷键与 Google 文档一致。窄屏时排版部分横向滚动，两端渐隐提示还有内容。输入 `- `、`1. `、`# ` 等会自动转为列表和标题，Tab 调整列表层级，空列表项回车退出列表，标题后回车回到正文。
- **模型**　段落仍以纯文本 `text` 为准，另带段落样式 `type/align/indent/lh` 和字符样式 `runs`（每段一组连续区间：粗斜体、下划线、删除线、字体、字号、颜色、高亮）。Diff、AI 改稿、取舍合成和溯源只看文字；文字变化后，样式按 Diff 结果迁移：未变的字原样保留，替换的字沿用原文第一个字的样式，新增的字沿用前一个字的样式。因此改稿和定稿保留排版，“只改格式”不会被算成 AI 的文字修改，历史里另用“格式”标出。
- **兼容**　存储结构从 schema 3 升到 4，原有文章按纯文本段落读入，不清除任何数据；读不了的数据先备份到 `redraft.prototype.v1.backup-时间戳` 再加载示例。新增排版示例《写日记的第一百天》，旧数据里没有时自动补上。
- **导出**　Markdown 保留标题、引用、列表和缩进、粗体、斜体、删除线；下划线、颜色、高亮、字体、字号、对齐和行距没有对应写法，只在 HTML 导出里保留。复制到外部应用时同时带 HTML；从外部粘贴只保留粗斜体、下划线、删除线、标题、列表、引用和对齐，颜色和字体丢弃；`Ctrl/⌘+Shift+V` 粘贴为纯文本。
- **验证**　新增 90 项富文本浏览器检查和 13 项布局检查，全部通过：单段和跨段选区排版，混合状态显示，工具栏点按后选区不丢，`Alt+F10` 进入工具栏、`Esc` 回到原选区；字体、字号、清除格式；标题、列表切换与编号，Tab 缩进；排版的撤销重做且不弹提示；在粗体或高亮里续写、待生效样式；中文输入法组字上屏继承样式、光标位置正确、可撤销；回车、退格的段落规则和自动格式；本应用内复制粘贴保留样式，外部 HTML 只留基础格式；刷新后样式不变；改稿、审阅、定稿保留标题、引用、列表、粗体和高亮，历史正确区分文字改动和仅格式改动；Markdown 与 HTML 导出；schema 3 迁移和损坏数据备份；1440、1024、390、360 宽度无溢出、无遮挡，深色模式。原有核心流程和编辑器检查调整到新入口后重新跑过，全部通过。
- **遗留**　没有图片、表格、链接和自定义颜色；字号只有预设档位；格式刷、样式模板留到原生应用。原生应用里字符样式对应 `NSAttributedString` 属性，段落样式对应 `NSParagraphStyle`，需要在 Loro 文档里以 Mark 形式和文字分层保存，Diff 仍只比较文字层。

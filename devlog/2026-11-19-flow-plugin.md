# Redraft Flow 插件

在 Redraft 聊天里调用 `$redraft-flow:start` 即可登记需求、按模块分工并查看本次运行。主 Agent 约定验收场景，子 Agent 用启动事件中的身份与任务关联。看板分别展示 Codex 启停事件和模块工作进展。插件只向已登记会话的本地数据库写入事件标识和时间。使用方法见[启动说明](../README.md#在-codex-中启动一次需求)。

在本机 Codex 0.140.0 安装了本地插件 0.1.0，并确认工作流以及两项钩子均可发现。首次安装后两项钩子等待用户审阅。11 项看板测试与 4 项插件测试通过。另用已安装的事件处理程序和临时工作树，从登记、跨工作树接收测试事件、绑定任务和重复停止一直验证到 HTTP 看板与显式验收。真实聊天中的自动通知需在用户信任钩子后验证。

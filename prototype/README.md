# Redraft 交互原型

这是 Redraft 的网页交互原型，用来体验[产品想法](../idea.md)里的完整改稿循环：先专心写作和排版，再标记段落请 AI 改稿，然后对照送审稿逐处取舍，每一轮都留在历史里，可以回看一句话的来历，也能把取舍积累成自己的写作范例。正式产品按[技术设计](../design.md)做原生 macOS 应用，这个原型不替代它。

## 怎样查看

- **直接打开**：用浏览器打开 [`dist/redraft-prototype.html`](dist/redraft-prototype.html)。这是一个单文件，样式和脚本都内联在里面，离线可用，不需要账号、密钥或网络。建议用最新版 Chrome、Edge 或 Safari 打开。
- **从源码运行**：`src/index.html` 也可以直接打开；或者在仓库根目录运行 `python3 -m http.server 8000`，再访问 `http://localhost:8000/prototype/src/`。
- **重新打包**：修改 `src/` 之后运行 `node prototype/build.mjs`，会重新生成 `dist/redraft-prototype.html`。不需要安装依赖。

内容保存在浏览器的本地存储里。想回到初始状态，在窗口工具栏右上角的“更多”菜单里选“恢复示例数据”。

默认配色是“纸面”。想和上一版对比，在“更多”菜单的“配色”里选“上一版”，即刻生效并记在本机；恢复示例数据不会改动这个选择。

## 建议的体验路线

1. 打开后是《阳台的一年》，一篇图文表混排的短文：两张自绘的示例图、一张种植记录表。图片、表格和一段文字已经标记给 AI，正文左侧有一道细竖线。点“改稿 3”，再到审阅里体验换图、单元格文字和表格行列的取舍（见下文“图片与表格”）。
2. 《写日记的第一百天》是一篇排好版的短文：标题、引用、编号列表、项目符号、粗体、高亮和右对齐署名。
3. 选中几个字，用顶部工具栏改字体、字号、颜色、高亮，或按 `Ctrl/⌘+B/I/U`。选区跨段、混合样式时，按钮显示为半按下。把光标放进一段，切换标题、列表、对齐、行距和缩进。输入 `- `、`1. `、`## ` 会自动变成列表或标题。
4. 点右上角的“改稿 2”（`Ctrl/⌘+Enter`）。模拟改稿结束后点“审阅”。
5. 在审阅里用 `J`/`K` 在修改之间移动，`A` 采用、`O` 保留、`E` 重写；也可以点修改处。排版照常显示，Diff 只标文字的增删。
6. 点“完成”生成定稿。排版跟随文字保留下来。
7. 切到“历史”：文字改动用删除线和下划线标出，只改了格式的段落标“格式”，不计入字数变化。
8. 光标放进一句话（也可以是一个单元格或图注），点工具栏右端的“更多”→“这句话的来历”，沿时间线看初稿、AI 改稿和自己的取舍。
9. 左侧“改写范例”汇总每次取舍；《给新同事的一封信》可以直接练习审阅；《Keeping a Notebook》演示英文。

## 产品理念与设计决策

| 理念（来源） | 原型中的设计 |
| --- | --- |
| 界面安静、自明，内容优先（用户反馈，参考 iOS 备忘录） | 默认只看到正文、标题上方的日期和两条细工具栏。没有横幅、引导文字、状态数字和卡片边框；检查器默认收起。主按钮只在需要时出现。按钮用常见图标，悬停只显示名称和快捷键。 |
| 在上方直接排版（用户反馈，参考 Google 文档） | 顶部常驻排版工具栏：正文和标题、字体、字号、粗斜体、下划线、删除线、颜色、高亮、对齐、行距、列表、缩进、清除格式。按钮反映当前或混合状态，点按不夺走焦点，选区保留；快捷键与 Google 文档一致。基础排版不放进二级菜单。 |
| Diff 和溯源建立在文字上（design.md） | 每段以纯文本为准，段落样式和字符样式分层保存。Diff、AI 改稿、定稿合成和溯源只看文字；样式按 Diff 结果随文字迁移。改格式不会被当成 AI 的文字修改，历史里另标“格式”。 |
| 自己改过一轮后，再标出想请 AI 修改的段落（idea.md） | 工具栏右端的“标记”给当前段或选中的几段选一个要求（更简洁、更具体、更顺口、语气更自然或自定义）。标记只是正文左侧一道细竖线，不改变版面。 |
| AI 按标记改稿，每完成一次就生成一个新版本（idea.md、design.md） | 送审时保存“送审稿”，AI 改完保存“AI 改稿”，取舍后生成“定稿”，三稿都带排版。改稿期间正文锁定，可以取消。 |
| 对照送审稿逐处取舍（idea.md） | 审阅视图按文章顺序呈现，未标记段落作为浅色上下文。每处修改可以保留、采用或重写，附一句说明。 |
| Diff 按阅读顺序呈现，只改一个标点也能看清（design.md） | 段落按稳定 ID 对齐，再按词比较，中文用系统分词；删除用删除线加底色，新增用下划线加底色。Diff 里不显示文字颜色，避免和增删颜色混淆。 |
| 每一轮都留在历史里，能找到一句话的来历（idea.md、design.md） | “历史”任选两稿对比；“这句话的来历”在各稿中逐级找到这句话，并写明你采用、保留或重写了什么。 |
| 改过的句子就是自己的写作范例（idea.md） | 每次完成审阅，每一处取舍都记入“改写范例”，可以筛选、搜索，跳回原文。 |
| 图片和表格融入同一条改稿流程（用户确认的范围） | 图片和表格是正文里的一个块，与段落一样有稳定 ID，可以标记、送审、对比和溯源。图片整张处理：插入、替换、删除或保留；图注、单元格文字走文字 Diff；表格增删行列作为单独的结构修改逐个确认。 |
| 本地优先，AI 服务可替换（design.md） | 内容保存在本机浏览器。AI 改稿完全由本地模拟，接口形态与设计中的改稿服务一致。 |

## 配色

两套配色共用同一组角色变量（`src/styles.css` 顶部），组件里不写具体颜色。

| 角色 | 纸面（默认） | 上一版 |
| --- | --- | --- |
| 正文纸面 | 暖白 `#fbfaf6`，深色为中性炭灰 `#1e1e1d` | 冷白 `#fdfdfc`，深色带蓝调 `#1e1e20` |
| 侧栏、工具栏、分割线 | 中性暖灰，材质只做轻微模糊，饱和度几乎不提升 | 淡紫灰，模糊时饱和度提升到 175% |
| 桌面背景 | 平静的暖灰渐变 | 紫、橙、青三团彩色光斑 |
| 强调色 | 系统蓝 `#1667d9`，深色 `#2f86f6`，只用于选区、标记、主按钮和焦点 | 蓝紫 `#4a56d0`，深色 `#7c86f0` |
| 当前项 | 侧栏选中行、审阅当前段用中性灰底，蓝色只留给正在处理的那一处修改 | 都用蓝紫浅底 |
| 品牌标 | 石墨色 | 蓝紫渐变 |
| Diff | 新增深绿、删除砖红，各自有浅底和线型区分，避开强调色的蓝 | 新增绿、删除玫红 |

纸面配色在浅色和深色下都检查过：正文、侧栏、按钮、Diff 增删的文字对比度不低于 4.5:1，辅助文字不低于 3:1；界面框架里没有紫色。文字颜色和高亮属于文档内容，两套配色里都保留紫色等选项。

## 界面结构

- **文章库**（左侧）：文章列表、搜索、待审阅和改稿中的标记、改写范例、新建文章。窄屏时变为抽屉。
- **窗口工具栏**：文章库开关，“写作 / 审阅 / 历史”，按需出现的主按钮，“更多”（导出 Markdown、导出 HTML、字数统计、快捷键、关于、恢复示例），检查器开关。
- **排版工具栏**（只在写作时出现）：见上文。右端固定“标记”和“更多”（上移、下移段落，存为版本，这句话的来历）。宽度不够时排版部分横向滚动，两端渐隐。正文锁定时按钮变为不可用，右端显示一个锁。
- **正文**：不透明纸面，阅读宽度约 38 个字，正文 17 px，行高 1.9。
- **检查器**（默认收起）：写作时是“改稿”和“来历”，审阅时是当前修改的原句、改句和操作，历史时是版本时间线。
- **浮层**：菜单、色板、对话框、提示条使用较厚的材质和阴影。

## 图片与表格

**入口**：排版工具栏“清除格式”之后的两个按钮。图片也可以直接粘贴或拖进正文。

| 项目 | 支持 |
| --- | --- |
| 插入图片 | PNG、JPEG、GIF、WebP、AVIF、BMP、SVG，最大 20 MB，插在光标所在段落之后。图片只存在本机浏览器里，不上传；较大的位图会缩到长边 1800 px 再保存。 |
| 编辑图片 | 点图片选中，浮出“小 / 中 / 大”（正文宽度的 40% / 66% / 100%，不超过原图宽度）、替换、替代文字、删除。图注直接写在图片下方。`Backspace`/`Delete` 删除选中的图片，`Enter` 或方向键回到正文。 |
| 插入表格 | 网格里选 1–8 行、1–8 列，默认 3 × 3；两行以上时第一行是标题行。之后最多 40 行、8 列。 |
| 编辑表格 | 单元格里直接输入；`Tab`/`Shift+Tab` 前后移动，最后一格再按 `Tab` 新增一行；方向键到格子边缘时跨格；`Esc` 选中整张表，再按 `Backspace` 删除。右上角的“…”菜单：上方 / 下方插入行，左侧 / 右侧插入列，删除行或列，标题行开关，删除表格。 |
| 撤销与保存 | 插入、替换、改大小、替代文字、增删行列、删除整块都能撤销重做；连续输入合并为一步。删除整张图片或表格时提示条带“撤销”。刷新后内容不变。 |
| 审阅 | 换图并排显示原图和新图，删去的图片变灰；图注和单元格文字逐处取舍；新增的行或列整条绿底，删去的整条红底加删除线，每条是一处单独的修改。结构修改只有“保留 / 采用”，没有“重写”。 |
| 历史与来历 | 任意两稿对比同样显示换图、单元格文字和行列增删；来历可以落到一个单元格或图注。 |
| 导出 | HTML 保留全部内容：图片内嵌为 data URL，带图注、替代文字和显示大小；表格带标题行。从本应用复制粘贴保留图片和表格。 |
| Markdown | 图片写成 `![替代文字](data URL)`，图注另起一行斜体，显示大小丢弃；表格写成 GFM 表格，`|` 转义、单元格内换行写成 `<br>`，没有标题行时补一行空表头。 |

**示例**：《阳台的一年》里的图片、表格和第五段已标记。模拟改稿会把阳台全景换成番茄近景并改图注，精简两格备注，删去和“备注”重复的“状态”列，补上一行“六月”。

**限制**：没有公式、合并单元格、单元格内排版、列宽调整、图片裁剪和链接。模拟 AI 不识别图片内容：换图和增删行列只来自示例预置，其他图片和表格只对图注和单元格文字做本地规则精简。本地存储空间有限（通常 5 MB 左右），装不下时会提示“存储空间不足，图片没有插入”或“存储空间已满，最近的修改没有保存”；不支持的文件会提示“不支持这种图片格式”“只能插入图片文件”或“无法读取这张图片”。没有被任何文章或版本引用的图片在下次打开时清理。

## 排版能力与边界

| 项目 | 可选 |
| --- | --- |
| 段落样式 | 正文、标题 1、标题 2、标题 3、引用、项目符号、编号列表（编号按层级 1. / a. / i.） |
| 字体 | 黑体（系统无衬线）、宋体、楷体、等宽；系统缺少对应中文字体时退回默认字体 |
| 字号 | 12–40 px 的 14 档预设，`Ctrl/⌘+Shift+.`、`,` 逐档增减 |
| 字符样式 | 粗体、斜体、下划线、删除线、6 种文字颜色、5 种高亮 |
| 段落设置 | 左、中、右、两端对齐；行距 1.35 / 1.6 / 1.9 / 2.3；缩进 0–6 级 |

- 没有链接、自定义颜色和格式刷。
- 新输入的文字沿用前一个字的样式；在空光标处切换粗体等，会作用于接下来输入的文字。
- 从其他应用粘贴时只保留粗斜体、下划线、删除线、标题、列表、引用和对齐；从本应用复制粘贴保留全部样式；`Ctrl/⌘+Shift+V` 粘贴为纯文本。
- Markdown 导出保留标题、引用、列表和缩进、粗体、斜体、删除线，图片和表格按上文转换；其余样式只在 HTML 导出里保留。
- AI 改稿后，被替换的字沿用原文第一个字的样式，新增的字沿用前一个字的样式。这是近似规则，长段落改写后可能需要手动补排版。
- 旧版本的本地数据会自动迁移，原有文章和排版原样保留，并补上图文表示例；无法读取的数据先备份到 `redraft.prototype.v1.backup-时间戳`，不会被清除。

## 键盘与可访问性

- `Ctrl/⌘+/` 显示快捷键表。排版：`Ctrl/⌘+B/I/U`，`Ctrl/⌘+Shift+X` 删除线，`Ctrl/⌘+Alt+0–3` 正文和标题，`Ctrl/⌘+Shift+7/8` 编号和项目符号，`Ctrl/⌘+[`、`]` 缩进，`Ctrl/⌘+Shift+L/E/R/J` 对齐，`Ctrl/⌘+\` 清除格式。
- 排版工具栏是一个 `role="toolbar"`，只占一个 Tab 停留点：`Alt+F10` 进入，`←`/`→` 移动，`↓` 打开菜单，`Esc` 回到正文原来的选区。按钮都有无障碍名称和按下状态（包括混合状态）。
- 审阅里只有当前修改处在 Tab 序列中，用 `J`/`K` 移动；每处修改有完整的朗读标签。
- 跟随系统深色模式；`prefers-reduced-motion` 时关闭动画；高对比度模式下删除线和下划线仍然区分修改。
- 支持宽桌面、中等宽度和手机宽度。

## 演示与真实功能的边界

**真实运行**：富文本编辑与排版、图片与表格的插入编辑和审阅、输入法组字、分段与合并、自动格式、复制粘贴、段落移动、撤销与重做、标记和要求、送审与取消、版本快照、逐处取舍与定稿合成、任意两稿对比、逐句溯源、改写范例、Markdown 与 HTML 导出、本地存储与迁移。Diff 在浏览器里实时计算。

**模拟**：AI 改稿。示例段落使用预置改法和说明（包括示例图片的替换和示例表格的行列修改）；其他段落只做删赘词等少量本地规则精简，没有可改之处时显示“没有修改”。自定义要求会被记录，但模拟服务不会理解它。没有网络请求，也没有后端。

**没有做**：真实模型接入与密钥管理、多设备同步、原生 macOS 的系统能力（拼写检查、Writing Tools、字体面板等）。

## 与技术设计的对应

| 原型文件 | 对应 design.md 中的模块 |
| --- | --- |
| `src/diff.js` | 文本对比：段落按 ID 对齐，`Intl.Segmenter` 分词（对应 NLTokenizer），词元 LCS，短间隔合并。 |
| `src/rich.js` | 排版层：段落样式和字符样式区间、样式随 Diff 迁移、渲染与解析、剪贴板、Markdown 与 HTML 导出。对应原生应用里 `NSAttributedString` 属性和 Loro 文档中的 Mark。 |
| `src/blocks.js` | 图片与表格：块的数据结构、本地图片存储与回收、导入校验、行列操作、导出和粘贴。图片和表格在原生应用里对应文档中的嵌入对象，图片文件放在文档包内。 |
| `src/session.js` | 文章会话、文档与版本：送审、生成 AI 版本、取舍合成定稿、逐句溯源。段落 ID 代替 Loro Cursor 提供稳定身份。 |
| `src/mock-ai.js` | AI 改稿服务的 Mock：输入标记段落和要求，返回改写文本和说明。 |
| `src/app.js`、`src/styles.css` | 编辑界面与本地文章库。 |
| `src/samples.js`、`src/sample-art.js` | 示例文章；示例图片是自绘的中性 SVG。 |

## 测试情况

在 Linux 上的 Chrome 157（无头）实测：图片插入、图注、大小、替代文字、替换、删除与撤销，四类错误提示，存储已满；表格插入、`Tab` 与方向键、增删行列、标题行、整表删除与撤销；保存刷新；《阳台的一年》的换图、行列结构和单元格取舍、定稿、历史、单元格来历、撤销定稿；Markdown 与 HTML 导出；含表格的复制粘贴；富文本、配色切换、文字文章的审阅和历史回归；schema 3、4 和无法识别数据的迁移，缺失图片的占位和损坏表格的回退；深色模式与 390 px 窄屏。

**尚未覆盖**：Safari、Firefox、Edge 和移动浏览器上的实机测试，中文输入法在单元格和图注里的组字，触屏拖放，屏幕阅读器朗读，接近存储上限的大量真实照片，原生 macOS 应用。
